The blog runs on your computer and the code is on GitHub, but it is not published anywhere yet. That step depends on which host you choose.

## What any host needs

- **Build command:** `npm run build`
- **Folder to publish:** `dist`
- **Fallback page:** every address should serve `index.html`. The site handles its own addresses, so without this a link straight to a post shows the host's error page.

## Try the finished site locally

```bash
npm run build
npm run preview
```

The first command builds the site into `dist`. The second serves that folder so you can click through it exactly as visitors will.
