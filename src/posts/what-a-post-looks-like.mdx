This starter post has no story to tell. It exists to show how each kind of text looks on the page, so you can decide what to use.

## A section heading

Paragraphs sit under headings like this one. Keep them short and the page stays easy to read on a phone. Links look [like this](/about) and get a pink underline.

### A smaller heading

Use these to break up a long section.

> A quote stands out from the text around it. Use one for the line you most want people to remember.

## Lists

Things in no particular order:

- A first thing
- A second thing
- A third thing

Steps that happen in order:

1. Do this first
2. Then this

## Code

Short code sits inside a sentence, like `npm run dev`. Longer code gets its own block:

```js
const posts = ['first', 'second', 'third']
console.log(`You have ${posts.length} posts`)
```
