A post with no cover photo gets a block in its category's color, like the one above. That is on purpose, so a post never looks unfinished.

## Give a post a cover photo

1. Make a folder at `src/posts/images` and put the photo in it.
2. Import the photo at the very top of the post and add it to the block that describes the post:

```js
import cover from './images/beach.jpg'

export const meta = {
  title: 'A week at the beach',
  date: '2026-10-20',
  category: 'Life',
  excerpt: 'Seven days, one sunburn.',
  cover,
  coverAlt: 'Waves at sunset',
}
```

`coverAlt` describes the photo for people who cannot see it.

## Put a picture inside a post

Import it the same way, then use it where you want it to appear:

```js
import shells from './images/shells.jpg'

<img src={shells} alt="A handful of shells" />
```

Wide pictures work best. Around 1600 pixels across is plenty.
