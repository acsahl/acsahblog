The blog starts with four categories. Each one has a color that shows up on its label and on the cover block of its posts.

- **Code** is blue
- **Projects** is green
- **Life** is pink
- **Notes** is butter yellow

## Change them

The list lives in `src/site.config.js`:

```js
categories: {
  Code: 'blue',
  Projects: 'green',
  Life: 'pink',
  Notes: 'butter',
},
```

Rename a category by changing its name here and in every post that uses it. Add a new one by adding a line. The order of this list is the order of the filter buttons.

A category only gets a filter button once at least one post uses it.

## Change the colors themselves

The four colors are defined at the top of `src/styles/tokens.css`. Change a value there and it changes across the whole site.
